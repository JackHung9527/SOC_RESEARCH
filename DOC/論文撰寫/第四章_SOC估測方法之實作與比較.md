## 4.0 本章共同前提

本章三種方法皆掛載於第三章 3.2 節所述之 STM32 韌體骨架，替換的僅是 `soc_soh_calc` 模組內的估測核心，其餘量測路徑（INA226 校正後電流／電壓）、時間基準（100 µs 系統節拍）、輸入輸出（heartbeat 串流）完全一致，以確保比較之公平性。為使三法在同一座標上比較，先統一界定下列共同量與符號。

**取樣與時間基準**：MCU 端 SOC 估測以 1 Hz 更新（與 heartbeat 同步，$\Delta t = 1$ s），其資料來源為 INA226 經 14 點 LUT 校正後之電流 $I_k$（放電為正）與端電壓 $V_{t,k}$。儀錶端（IT6302／IT8512A+）真值以 0.4 s 取樣作為交叉驗證。電流量測經第三章校正後全範圍誤差 $< 0.21$ mA（$< 1‰$），此為三法共同的量測根基。

**SOC 真值（ground truth）之界定**：本章以庫倫計數作為其他方法的精度對照基準（4.1 節說明其作為真值之正當性）。為消除電流偏移之長期漂移對「真值」本身的污染，逐 cycle 的 SOC 真值定義為「以該 cycle 實測滿放電容量 $q_{full}$ 正規化的庫倫積分」：

$$SOC_{truth}(t) = 1 - \frac{\int_{t_0}^{t} I(\tau)\, d\tau}{q_{full}}$$

如此使每個放電 cycle 的起點錨定於 100%、截止點錨定於 0%，兩端皆有絕對錨點，中間以高精度電流積分線性內插，是短至中時間尺度內可信賴的 SOC 參考（其侷限見 4.1.4）。

**受測電池**：客製化 NMC 鋰離子電池，標稱容量 $C_{rated} = 2000$ mAh，$V_{cv} = 4.2$ V，$V_{cut} = 2.5$ V。本章所有實驗均於室溫進行，不做溫度補償（列為第六章 limitation）。

**比較指標**（4.4 節展開，此處先界定符號）：

| 類別 | 指標 | 符號／定義 |
|---|---|---|
| 精度 | 均方根誤差 | $RMSE = \sqrt{\frac{1}{N}\sum_k (\widehat{SOC}_k - SOC_{truth,k})^2}$ |
| 精度 | 平均絕對誤差 | $MAE = \frac{1}{N}\sum_k \lvert \widehat{SOC}_k - SOC_{truth,k}\rvert$ |
| 精度 | 最大絕對誤差 | $e_{max} = \max_k \lvert \widehat{SOC}_k - SOC_{truth,k}\rvert$ |
| 精度 | 收斂時間 | $t_{conv}$：自錯誤初值起，誤差首次且持續落入 $\pm 2\%$ 帶之時間 |
| 強健性 | 初值錯誤恢復 | 初值偏移 $\pm 20\%$ 後之 $t_{conv}$ 與穩態誤差 |
| 強健性 | C-rate 切換 | 倍率階躍瞬間之誤差尖峰 |
| 嵌入式資源 | Flash／RAM／CPU | 模組淨增 Flash bytes、RAM bytes、每次更新 CPU cycles |
| 工程性 | 校正需求／LoC | 所需離線校正資料、實作行數 |

## 4.1 庫倫計數法（兼基準真值）

### 4.1.1 原理

庫倫計數法（安時積分法）對流經電池的電流積分以累計電量變化，由初始 SOC 遞推當前 SOC（符號與第二章 2.2.1 節一致，放電電流為正）：

$$SOC(t) = SOC(t_0) - \frac{1}{C_{rated}} \int_{t_0}^{t} \eta \cdot I(\tau)\, d\tau$$

其中 $\eta$ 為庫倫效率。本研究於充電方向取 $\eta_{chg}$、放電方向取 $\eta_{dis} \approx 1$；NMC 體系庫倫效率接近 1，室溫下單一 cycle 內以 $\eta = 1$ 近似所引入之誤差遠小於電流量測誤差，故實作上不另引入 $\eta$ 修正（其影響歸入長期漂移討論，4.1.4）。

庫倫計數之所以同時擔任本章三法比較的**基準真值**，理由有三：(1) 其估測完全由電流積分決定，不依賴電池模型參數，無模型失配風險；(2) 第三章已將 INA226 電流校正至 $< 1‰$，使積分核心可信；(3) 如 4.0 節所述，逐 cycle 以實測滿放容量正規化後，放電起訖兩端皆有絕對錨點，中段由高精度積分內插，短中時間尺度的相對 SOC 軌跡可信賴。需強調此「真值」僅在**單一 cycle 內**成立——跨 cycle 的長期漂移正是庫倫計數的根本弱點（4.1.4），故 4.2／4.3 之精度比較均在逐 cycle 重新錨定的框架下進行。

### 4.1.2 演算法

離散化後，每個取樣週期 $\Delta t$ 更新一次積分器。為與第三章「放電擾動期間庫倫不可漏計」之紀律一致，積分涵蓋包含 dV/dI 擾動 dwell 在內的每一秒：

```
每 Δt（= 1 s）執行：
    讀取校正後電流 I_k        // INA226 LUT 後處理，放電為正
    Δq      = I_k * Δt        // 本週期流出電荷（A·s）
    q_drawn = q_drawn + Δq    // 累計流出電荷
    SOC_k   = 1 - q_drawn / q_rated_As   // 夾限至 [0, 1]
```

PC 端參考實作見 `TEST/core/coulomb.py`：以 `CoulombCounter` 類別維護「已流出電荷」`_charge_drawn_mAs`（單位 A·s 換算為 mA·s），`update(I, dt)` 推進積分、`soc` 性質回傳夾限後 SOC、`ah_used` 回傳累計安時。其符號約定（放電正、充電負）與本章一致。

### 4.1.3 STM32 實作

庫倫計數於 MCU 上的實作極輕量，掛載於 `soc_soh_calc` 模組，核心為一個 64 位元定點累加器與一次乘加。為避免 32 位元浮點長時間累加之尾數丟失（1 Hz、數小時的積分達數萬筆），累加器採整數化的 µA·s 單位以 `int64_t` 維護，僅在輸出 SOC 時做一次除法轉換。核心邏輯（遵循專案 MISRA C 排版規範）：

```c
/*
 * @brief  庫倫計數 SOC 更新（1 Hz 呼叫一次）。
 *         參數說明：
 *           - i_ua    : 校正後電流，單位 µA，放電為正、充電為負
 *           - dt_ms   : 距上次更新之時間，單位 ms（標稱 1000）
 *         模組靜態狀態：
 *           - s_q_drawn_uas : 已流出電荷累計，單位 µA·s，int64_t
 *           - s_q_rated_uas : 額定容量，單位 µA·s（2000 mAh = 7.2e9 µA·s）
 */
void coulomb_update(int32_t i_ua, uint32_t dt_ms)
{
    int64_t dq_uas = (int64_t)i_ua * (int64_t)dt_ms / 1000; // 本週期電荷增量

    s_q_drawn_uas += dq_uas; // 累計流出電荷

    if (s_q_drawn_uas < 0)
    {
        s_q_drawn_uas = 0; // 夾限：不得超過滿電
    }
    if (s_q_drawn_uas > s_q_rated_uas)
    {
        s_q_drawn_uas = s_q_rated_uas; // 夾限：不得低於放空
    }
}

float32_t coulomb_get_soc(void)
{
    // 僅在需要輸出時做一次浮點除法，避免長期累加之尾數丟失
    return 1.0F - ((float32_t)s_q_drawn_uas / (float32_t)s_q_rated_uas);
}
```

此模組無矩陣、無查表、無浮點累加，每次更新僅一次 64 位元乘法、一次除法與兩次比較，是三法中資源占用的下界，作為 4.4 footprint 比較的參考底線。

### 4.1.4 實驗結果（rate-capability 與 ground-truth 有效性，實測）

庫倫計數的實驗結果同時驗證兩件事：其一為電流積分核心於本平台之自洽性（容量再現性），其二為其作為真值的有效範圍與漂移侷限。資料取自第三章 `round_runner` 跨輪協定累積之 `cycle_log.csv`（rounds 1–23，cycles 1–90，連續 2026-05-12 至 06-03）。

**fresh-cell 容量再現性與 rate capability（實測）**：以前三輪 fresh-cell baseline 各四種放電倍率之實測安時量（庫倫積分至截止），整理如表 4-1。

| 倍率 | Round 1 (mAh) | Round 2 (mAh) | Round 3 (mAh) | 平均保持率 |
|---:|---:|---:|---:|---:|
| 0.5C | 1677.6 | 1661.9 | 1657.5 | ~100.0% |
| 1.0C | 1651.8 | 1660.0 | 1658.7 | ~99.5% |
| 1.5C | 1646.7 | 1657.4 | 1655.7 | ~99.3% |
| 2.0C | 1644.9 | 1652.1 | 1647.4 | ~98.9% |

> 表 4-1　fresh-cell 三輪各倍率實測放電容量（庫倫積分，數據源 `cycle_log.csv` cycles 1–13）

兩項觀察：(1) 此 NMC 電池 **rate capability 極平坦**——自 0.5C 至 2.0C（1C = 2 A）放電容量僅下降約 1%，反映其內阻低、極化小，是後續方法比較的有利條件（高倍率下端電壓仍接近 OCV，模型失配較小）。(2) 同倍率跨輪再現性佳（0.5C 三輪 1657–1678 mAh），佐證 `round_runner` 協定與 INA226 校正之穩定性。此「滿放容量」即 4.0 節 SOC 真值正規化所用之 $q_{full}$。

**作為真值的漂移侷限（實測佐證 + 設計分析）**：庫倫計數作為**即時獨立方法**之根本弱點為誤差累積。以第三章校正殘差為例，雖然電流校正後 $< 0.21$ mA，但若殘餘偏移以最壞情形 $0.2$ mA 持續積分，1 cycle（約 2 h @ 0.5C）累積電荷誤差約 $0.2\text{ mA} \times 7200\text{ s} = 1.44$ A·s $\approx 0.4$ mAh，相對 2000 mAh 約 $0.02\%$／cycle——短期可忽略，但連續數百 cycle 無 OCV 修正將線性放大。`cycle_log.csv` 中 0.5C 容量自 round 1 的 ~100.8% 緩降至 round 19 的 ~98.4%，混合了**真實老化**與**測量再現性**，需第五章以三輪 baseline 變異性分離；就本章而言，重點在於：庫倫計數**無自我修正能力**，這正是 EKF 引入端電壓觀測修正的動機，也是 4.4 強健性比較中「初值錯誤恢復」一項庫倫計數必然失分之處。

**作為 ground truth 的使用方式（本章框架）**：4.2／4.3 兩法之精度評估，均以「逐 cycle 重新錨定的庫倫 SOC」為對照。具體流程為：對每個放電 cycle，以該 cycle 起點為 $SOC_{truth}=100\%$、以實測 $q_{full}$ 正規化積分得逐秒 $SOC_{truth}(t)$，再與待評估方法的 $\widehat{SOC}(t)$ 逐點相減計算 RMSE／MAE／$e_{max}$。此框架使「真值本身的長期漂移」被排除在比較之外，確保比較的是各方法的**模型／演算法能力**而非積分器漂移。

## 4.2 擴展卡爾曼濾波器（EKF）

> 本節原理、狀態空間、演算法與 STM32 實作為**設計完成**；4.2.5 之實驗結果依賴 (a) 第三章 GITT OCV 表之建立、(b) PC 端 EKF 原型調參、(c) STM32 移植，三者於本稿時點尚在進行，數值結果一律標 `[待測]`。

### 4.2.1 原理與狀態空間模型

EKF 將 SOC 視為動態系統的隱藏狀態，融合「電流積分（模型預測）」與「端電壓（量測更新）」兩路資訊，在過程雜訊與量測雜訊並存下對 SOC 做遞迴最小均方誤差估測，兼具庫倫計數的良好動態與 OCV 的絕對校正能力，並能自初值錯誤收斂（第二章 2.2.3 節）。

採第二章 2.1.3 節所述之一階 RC（戴維寧）模型作為基礎結構，狀態取 $\mathbf{x} = [SOC,\ V_1]^T$，輸入 $u = I$（放電為正），輸出 $y = V_t$。連續時間方程：

$$\begin{cases} \dot{SOC} = -\dfrac{\eta}{C_{rated}} I \\ \dot{V}_1 = -\dfrac{1}{R_1 C_1} V_1 + \dfrac{1}{C_1} I \\ V_t = V_{OC}(SOC) - I R_0 - V_1 \end{cases}$$

以取樣週期 $\Delta t$ 離散化（前向 Euler），得狀態轉移與觀測：

$$\mathbf{x}_{k+1} = \underbrace{\begin{bmatrix} 1 & 0 \\ 0 & e^{-\Delta t / \tau_1} \end{bmatrix}}_{\mathbf{A}_k} \mathbf{x}_k + \underbrace{\begin{bmatrix} -\eta \Delta t / C_{rated} \\ R_1\left(1 - e^{-\Delta t/\tau_1}\right) \end{bmatrix}}_{\mathbf{B}_k} I_k + \mathbf{w}_k$$

$$y_k = V_{OC}(SOC_k) - I_k R_0 - V_{1,k} + v_k$$

其中 $\tau_1 = R_1 C_1$。$V_1$ 之離散化採零階保持（ZOH）精確解 $e^{-\Delta t/\tau_1}$ 而非單純 Euler，以避免 $\Delta t$ 相對 $\tau_1$ 不夠小時的離散化誤差。

### 4.2.2 觀測非線性與線性化

觀測方程的非線性源自 $V_{OC}(SOC)$。本研究以第三章 3.7 節 GITT 建立之 pseudo-OCV 表 $V_{pseudo}(SOC)$ 作為此函數，於 MCU 上以分段線性內插求值。EKF 量測更新所需之觀測雅可比為：

$$\mathbf{C}_k = \frac{\partial y}{\partial \mathbf{x}}\bigg|_{\hat{\mathbf{x}}_k} = \begin{bmatrix} \dfrac{\partial V_{OC}}{\partial SOC}\bigg|_{\widehat{SOC}_k} & -1 \end{bmatrix}$$

其中 $\partial V_{OC} / \partial SOC$ 由 OCV 表相鄰 bin 的斜率取得（分段線性下即該段斜率）。為避免 GITT 表 5% 步長造成斜率階梯不連續而擾動濾波器，OCV 表於載入時先以 1% 細網格重新內插並平滑，使雅可比連續（細節見 4.2.4）。

### 4.2.3 演算法（標準 EKF 遞迴）

每個 1 Hz 週期執行一次「預測—更新」遞迴：

```
預測（時間更新）:
    x_pred = A_k * x_hat + B_k * I_k            // 狀態先驗
    P_pred = A_k * P * A_k^T + Q                // 誤差協方差先驗
更新（量測更新）:
    y_pred = OCV(x_pred.SOC) - I_k*R0 - x_pred.V1   // 端電壓預測
    C_k    = [ dOCV/dSOC(x_pred.SOC) , -1 ]     // 觀測雅可比
    S      = C_k * P_pred * C_k^T + R           // 殘差協方差（純量）
    K      = P_pred * C_k^T / S                 // 卡爾曼增益（2x1）
    x_hat  = x_pred + K * (V_meas - y_pred)     // 狀態後驗
    P      = (I - K * C_k) * P_pred             // 協方差後驗（Joseph 式見實作）
    SOC_k  = clamp(x_hat.SOC, 0, 1)
```

維度極小（狀態 2 維、觀測 1 維），故 $\mathbf{S}$ 為純量、增益計算僅需一次純量除法，無需一般矩陣求逆——這是 SOC-EKF 在嵌入式上可行的關鍵。協方差更新採 Joseph 穩定形式以維持 $\mathbf{P}$ 對稱正定。

**參數來源**：$R_0, R_1, C_1$ 由放電脈衝鬆弛實驗辨識（利用第三章 dV/dI 擾動段之電壓階躍與回彈，以最小平方擬合一階 RC）；$Q$（過程雜訊）、$R$（量測雜訊，由 INA226／端電壓量測噪聲統計取得）為調參對象。`[待測]` 上述 RC 參數之辨識值與 $Q, R$ 之最終調定值待 PC 原型完成後填入。

### 4.2.4 STM32 實作

EKF 模組於 `soc_soh_calc` 內以單精度浮點實作（STM32G071 無 FPU，浮點走軟體模擬，故 CPU 週期顯著高於庫倫計數，此正是 4.4 待量化之代價）。設計要點：

- **OCV 表**：載入時將 GITT 21 點（5% 步長）細化為 101 點（1% 步長）`const float32_t` 陣列存於 Flash，查值與求斜率各為一次線性內插，避免執行期重算。
- **矩陣運算展開**：因維度固定為 2×2／2×1，所有矩陣運算手動展開為純量算式，不引入通用矩陣函式庫，省去迴圈與函式呼叫開銷並便於 cycle 計數。
- **數值穩定**：$\mathbf{P}$ 以 Joseph 形式更新並週期性強制對稱化（$\mathbf{P} \leftarrow (\mathbf{P}+\mathbf{P}^T)/2$）；SOC 後驗夾限至 $[0,1]$。
- **初始化**：$\widehat{SOC}_0$ 可任意（EKF 應能收斂），$\mathbf{P}_0$ 取較大值以反映初值不確定、加速收斂。

```c
/*
 * @brief  EKF 一步遞迴（1 Hz 呼叫）。一階 RC 模型，狀態 [SOC, V1]。
 *         參數說明：
 *           - i_a     : 校正後電流，單位 A，放電為正
 *           - v_meas  : 量測端電壓，單位 V
 *           - dt_s    : 取樣週期，單位 s（標稱 1.0）
 *         模組靜態狀態：x_hat[2]、P[2][2]、已辨識之 R0/R1/C1、Q[2][2]、R_meas
 */
void ekf_update(float32_t i_a, float32_t v_meas, float32_t dt_s)
{
    // 時間更新、量測更新之純量展開實作（2x2），詳見 soc_soh_calc/ekf.c
    // [待測] 完整實作隨 PC 原型定版後移植並回填本處節錄
```

## 4.3 動態阻抗法

> 本節原理、演算法與 STM32 實作為**設計完成**；4.3.4 之 $\Delta V/\Delta I$–SOC 擬合係數與精度依賴對既有擾動數據之系統性萃取與韌體化，本稿時點尚未完成，數值結果標 `[待測]`。

### 4.3.1 原理

動態阻抗法（Lin 2016 [2]）避開「需初始值」與「需長時間靜置」兩大限制，改以電池工作中端電壓對電流的瞬時變化率推估 SOC。定義動態阻抗為相鄰擾動兩點之電壓差比電流差：

$$Z_{dyn} = \frac{\Delta V}{\Delta I} = \frac{V_1 - V_2}{I_1 - I_2}$$

該文獻關鍵發現為 $Z_{dyn}$ 與 SOC 呈近似拋物線關係，可二次擬合（第二章 2.2.4 節）：

$$\frac{\Delta V}{\Delta I} = a\,(SOC)^2 + b\,(SOC) + c$$

物理上，電池於接近滿電與接近放空時動態阻抗較高、$SOC \approx 50\%$ 附近最小。因拋物線對稱，單一 $Z_{dyn}$ 對應兩個可能 SOC，須以 $Z_{dyn}$ 對 SOC 之變化率正負判別位於曲線哪一側以取唯一解 [2]。

### 4.3.2 擾動數據來源（與第三章協定耦合）

本研究的跨輪測試協定已對四種放電 C-rate 注入 dV/dI 擾動：每 60 s 由基礎倍率短暫步降至 0.2C、dwell 1 s 後步回（第三章 3.6 節）。取步降前後兩穩態樣本即得該 SOC 下之 $\Delta V/\Delta I$。由於庫倫計數提供逐秒 SOC，每個擾動事件可標記其發生時的 SOC，從而對「$\Delta V/\Delta I$ vs SOC」累積散點。基礎倍率越高、$\Delta I$ 越大、dV/dI 訊噪比越好，故四種倍率全數注入擾動——高倍率數據對拋物線擬合尤為有利。

此設計使動態阻抗法**無須額外實驗**，直接複用 rate-capability 數據中既有的擾動段，是其「嵌入式友善＋實驗成本低」的體現。

### 4.3.3 演算法

```
建表階段（離線，PC）:
    對每個放電 cycle 的每個擾動事件:
        取步降前穩態 (V1, I1)、dwell 末穩態 (V2, I2)
        Z = (V1 - V2) / (I1 - I2)
        soc = 庫倫真值 @ 該事件時刻
        累積散點 (soc, Z)
    最小平方擬合 Z = a*SOC^2 + b*SOC + c    // 得 a, b, c
    記錄頂點 SOC* = -b/(2a)                  // 拋物線最小值位置，判枝用

即時估測階段（MCU）:
    每偵測到一次擾動事件:
        Z = (V_before - V_after) / (I_before - I_after)
        解 a*SOC^2 + b*SOC + (c - Z) = 0     // 兩根
        以「Z 對 SOC 變化率正負」或前一 SOC 鄰近性選正確根
        SOC_k = 選定根（夾限 [0,1]）
    擾動事件之間: 以庫倫計數內插維持連續 SOC（混合策略）
```

需注意動態阻抗法**僅在擾動事件發生時**產生獨立估測（本協定為每 60 s 一次），事件之間若需連續 SOC，實務上以庫倫計數內插。故嚴格而言本法在本平台為「動態阻抗離散校正 + 庫倫內插」的混合形態，4.4 比較時將如實標註此特性。

## 4.5 本章小結

本章於第三章建立的統一平台上，依「原理 → 演算法 → STM32 實作 → 實驗結果」一致結構，實作並比較三種 SOC 估測方法。**已完成且實測**者為：庫倫計數法之 PC／STM32 設計、其作為逐 cycle ground truth 的正當性論證，以及 rounds 1–23 之 rate-capability 實測（此 NMC 電池 0.5C→2.0C 容量僅降約 1%，rate capability 極平坦，為公平比較之有利條件）。**設計完成、實驗待跑**者為：EKF（一階 RC，狀態 2 維、觀測純量、增益免矩陣求逆，以 GITT OCV 表為觀測方程）之完整演算法與 STM32 浮點實作設計；動態阻抗法（複用既有 dV/dI 擾動、二次擬合 + 分枝選根）之演算法與輕量實作設計；以及 4.4 之精度／強健性／footprint 三軸比較框架與表骨架。
